# Ícones dos projetos

Os cards da biblioteca da Wiki priorizam `media.icon`, que aponta para
`/img/projects/<id>/pack_icon.png`. As imagens são cópias dos ícones dos
resource packs, sem recorte, redimensionamento ou substituição por renders.

O mapper resolve a pasta do RP pelo `config.json` do addon e usa somente
`RP/pack_icon.png` (ou a pasta configurada). Os projetos legados mantêm seus
caminhos explícitos em `website/project-catalog.config.jsonc`.
