A **Paxel** combines a pickaxe, axe and shovel. An **AIOT** (All-In-One Tool) adds the sword and hoe functions, including a 3×3 farming action. This guide uses the item definitions from version **1.0.5**.

## Recipes {#recipes}

| Tool | Ingredients |
| --- | --- |
| Paxel | 1 pickaxe, 1 shovel and 1 axe of the same material, plus 4 string and 2 sticks |
| AIOT | 1 Paxel, 1 sword and 1 hoe of the same material, plus 3 units of that material, 2 string and 1 stick |
| Netherite Paxel or AIOT | Upgrade the corresponding diamond tool with 1 Netherite Upgrade smithing template and 1 netherite ingot at a smithing table |

For a wooden AIOT, use planks as the extra material. Use cobblestone for stone tools and ingots for copper, iron and gold. Diamond requires three diamonds.

### Crafting grid {#crafting-grid}

Slots run left to right, from the top row to the bottom row.

| Row | Paxel | AIOT |
| --- | --- | --- |
| Top | String · Shovel · String | Material · Sword · Material |
| Middle | Axe · Stick · Pickaxe | String · Paxel · Hoe |
| Bottom | String · Stick · String | Stick · String · Material |

## Use an AIOT on a block {#actions}

- Use while standing to till eligible soil and harvest supported crops in a 3×3 area.
- Use while sneaking to turn eligible soil into dirt paths in a 3×3 area.
- Using the tool also clears snow and snow layers in the 3×3 area at the targeted height and one block above. You can use this action while standing or sneaking.
